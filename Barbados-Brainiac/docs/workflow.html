Barbados-Brainiac workflow

How the pipeline turns Train.csv, Test.csv, the line images and the two mega prompts into submission.csv: 18 stages run one after another, and the two approaches meet in one candidate pool.

R.O.A.D. score = 0.5 · (1 − word edits / 12) + 0.5 · (1 − char edits / 55)

Layers

LayerWhat it doesStages
PrepareBuilds the line table: split, family A (1639–1668 strips) or B (1669–1710 crops), near-duplicate groups kept in one fold, 5 folds. Renders the model input views.prepare · views
Approach AThe 1st-place recipe: VLM label correction, dual-target LoRA (ink + transcription), pseudo labels on test and unlabelled images, final LoRA.label_correction … a_infer
GenerateFine-tuned VLMs (two soups, one rank-64 LoRA) and the approach A models write about 14 candidate lines each. The CRNN adds beam-8 strings.b_train_generators … b_pool
ScoreSix VLM judges (forced-decode log-probs), the CTC reader and a character n-gram LM score every candidate.b_judges · b_features
PickA gradient-boosted ranker learns from the holdout-fold lines which evidence to trust. The judge-mix → MBR → CTC baseline is its reference.b_baseline · b_rank
Stabilise3 CatBoost members × 5 seeds, averaged within each line, with threads and seeds pinned.b_rank
GatesTwin → tier 1 → Holm → K5 → seed flip ≤ 3 % decide whether the ranker replaces the baseline.b_rank
FuseWrites one submission per method, fills gaps along the fallback order, and picks the primary by the gates.fuse · report

Components

ModuleRole
brainiac/run.pyStage runner: the 18 stages one after another, resumable, config overrides as key=value.
brainiac/config.pyYAML includes, ${…} interpolation, command-line overrides.
brainiac/data/dataset.pyLine table, families, near-duplicate groups, folds, scopes.
brainiac/data/views.pyModel input views, the patchify step for lines.
brainiac/text/prompts.pyMega-prompt sections (full, compact or chosen), correction prompt, answer JSON, parsing.
brainiac/text/clean.pyOutput cleaning to the collection's character set.
brainiac/vlm/Model registry (Qwen2.5-VL-7B, Qwen3-VL-8B), hf / vllm / mock backends, LoRA training, LoRA soups.
brainiac/readers/CRNN CTC reader (training, beam search, candidate likelihoods) and external readers.
brainiac/lm/charlm.pyKneser-Ney character n-gram LM.

brainiac/pipeline/approach_b.pyGenerators, soups, candidate generation, readers, candidate pool, judges.
brainiac/pipeline/features.pyF0–F3 and reader features; target = exact metric loss.
brainiac/pipeline/selection.pyMBR baseline, GBDT ranker with nested CV, stabilisation, gates.
brainiac/pipeline/fusion.pyPer-method submissions, primary pick, holdout-fold report.
brainiac/metric.pyR.O.A.D. metric, per-line loss, loss matrices, paired bootstrap.
